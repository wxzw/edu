# 社区英语组班管理端

Vue 3 + TypeScript + Element Plus 管理后台，已对接后端一期接口。

## 页面

- 登录
- 工作台
- 校区管理
- 用户管理
- 角色权限
- 老师管理
- 课程管理
- 班级管理

## 本地启动

```powershell
npm install
npm run dev
```

默认地址：

```text
http://localhost:5173
```

Vite 已将 `/api` 代理到：

```text
http://localhost:8080
```
